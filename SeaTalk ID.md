# SeaTalk ID

SeaTalk ID is the ID for each SeaTalk account, including the normal user and the bot.

How to check the SeaTalk ID?

* The user can check the SeaTalk ID in the app "Me > SeaTalk Profile > SeaTalk ID"
* The bot SeaTalk ID can be checked on the SeaTalk Open Platform "App > Bot > SeaTalk ID" ([https://open.seatalk.io](https://open.seatalk.io))
* API "Get Employee Profile" respond the parameter including SeaTalk ID (https://open.seatalk.io/docs/get-employee-profile)

What I can do with the SeaTalk ID?

* To know who is the sender of the message mentions the bot ([https://open.seatalk.io/docs/event\_new\_mentioned\_message\_from\_group\_chat](https://open.seatalk.io/docs/event_new_mentioned_message_from_group_chat))
* To mention a user in the group chat ([https://open.seatalk.io/docs/Send-Message-to-Group-Chat](https://open.seatalk.io/docs/Send-Message-to-Group-Chat))
* To know who is in the group chat ([https://open.seatalk.io/docs/get-group-info](https://open.seatalk.io/docs/get-group-info))

What is the difference between SeaTalk ID and Employee Code?

* A SeaTalk ID is a unique identifier associated with a SeaTalk user account. Meanwhile, a SeaTalk account has the capability to join multiple organizations, each of which creates its own distinct organization profile within the SeaTalk platform. The employee code serves as the identifier for the SeaTalk account's association with a specific organization profile.
