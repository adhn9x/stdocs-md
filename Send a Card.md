# Send a Card

After understanding how to [Build a Card](/docs/interactive-msg_build-a-card), it's time to see it for yourself by sending interactive message cards out. This document introduces the currently supported channels where your app can send out an interactive message card.

# Send a Card to Application Center

Interactive message cards can be sent to Application Center, a one-way communication channel for apps to push service notices to app users. A user can receive service notices from more than one app in Application Center.

To understand in more detail, see [Send Service Notice](/docs/messaging_send-service-notice) .

# Send a Card to a Bot User

Interactive message cards can be sent to a bot user. To understand in more detail, see [Send Message to a Bot User](/docs/messaging_send-message-to-bot-subscriber_).

# Send a Card to a Group Chat

Interactive message cards can be sent to a group chat by a bot or a system account. To understand in more detail, see [Bot Send Message to Group Chat](/docs/Send-Message-to-Group-Chat) and [System Account Send Messages to Group Chat](/docs/system-account).
